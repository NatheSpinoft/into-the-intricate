## Workflow

1. **Pick a Section**  
   Example: HTML Basics → Copy examples from W3Schools into `exercises/01_html_basics/index.html`.

2. **Type It Yourself**  
   Don’t just copy-paste. Type it manually in VSCode. This is the “hard way” principle.  

3. **Experiment**  
   - Change tag attributes.  
   - Modify styles.  
   - Add new elements.  
   - Break things on purpose and fix them.  

4. **Document Notes**  
   Use `README.md` in the root or per folder to jot down what you learned or common pitfalls.  

5. **Build Mini Projects**  
   Every 2–3 sections, consolidate knowledge by creating a small project in `projects/`. Example:  
   - After HTML basics → Build a personal bio page.  
   - After CSS basics → Style that page with colors, layouts, and fonts.  

6. **Run Locally in VSCode**  
   - Install **Live Server** extension → right-click `index.html` → “Open with Live Server.”  
   - See changes instantly as you tweak code.  

7. **Version Control (Optional)**  
   - Initialize a git repo: `git init`  
   - Commit exercises regularly → good for reviewing progress and backup.
